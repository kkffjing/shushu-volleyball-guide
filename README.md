面向高校社团与排球爱好者的通识学习资料。

阅读地址：https://kkffjing.github.io/shushu-volleyball-guide/

2026年10月25日更新：开篇、8章41节正文、裁判手势附录，含个人技术、发接发与攻防、位置配合、历史、统计及带队方法。正文附44个不同的B站视频入口，参考资料与图片出处列在章末。

适合小范围试读；不同地区与网络的访问情况请以实际打开为准。

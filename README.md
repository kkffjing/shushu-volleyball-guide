# 鼠鼠排球指南

供高校排球社团与排球爱好者阅读、交流的通识学习资料，包含正文、配图、练习和记录模板。参考资料及图片来源列在各章末尾。

## 网页文件

- `index.html`：完整阅读页面。
- `assets/`：页面使用的图片。
- `downloads/`：可下载的记录模板。

这是纯静态网页，无需安装依赖或执行构建。上传时请保留文件夹结构。

## GitHub Pages

将本目录中的全部文件上传到仓库的 `main` 分支根目录（包括 `.nojekyll`）。在仓库 Settings → Pages 中，选择 Deploy from a branch，分支选 `main`，目录选 `/ (root)`。发布地址以 GitHub Pages 设置页实际显示的结果为准。

适合小范围试读。国内不同网络的访问情况需要实际测试。
